# anonmav-data

Public JSON for [anonmav.com](https://anonmav.com). Pages may load these files as a free live data source and fall back to the copies bundled with the site.

## Files

- `ledger.json` — graded alerts and executed-bot records (schema 2). Earlier-run dollar amounts are not published; current-run net after fees may be.
- `longshot/today.json` — tonight's Long Shot board
- `longshot/feed.json` — From X sports posts
- `longshot/record.json` — Long Shot win/loss/pending record
- `longshot/slate.json` — slate snapshot
- `longshot/splits.json` — public betting splits

Times are America/Phoenix unless a field says otherwise.

Educational information, not financial advice. Past performance does not guarantee future results.
